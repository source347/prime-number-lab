# Prime Number Lab

An interactive browser-based laboratory for prime numbers, prime distributions, Euler's product, zeta zeros, and the Riemann explicit formula.

The site is deployed with GitHub Pages. Open `index.html` locally or visit the GitHub Pages URL.

## Mathematical scope
- Prime generation, primality, factorisation, gaps, twin primes
- Prime-counting function versus x/log(x) and logarithmic integral
- Prime reciprocal partial sums
- Euler product for Re(s) > 1
- Zeta-zero visualisation and truncated explicit-formula terms
- Sum-of-two-squares theorem

The Riemann Hypothesis is an open conjecture. This project is educational software, not a proof. A finite truncation of the explicit formula is not the exact prime-counting function.
